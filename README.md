# Delhi Capitals IPL Performance Analysis (2022–2024)

## Overview
A Power BI dashboard analysing Delhi Capitals' performance across IPL 2022–2024 using ball-by-ball data covering 52,868 deliveries across 209 matches.

## What's Inside
- Phase-based analysis — Powerplay, Middle Overs, Death Overs
- Match-by-match RAG performance tracker
- Batting and bowling performance metrics
- DAX measures for advanced calculations
- RAG conditional formatting for instant performance insights

## Tools Used
- Power BI Desktop
- DAX
- Microsoft Excel

## Data Source
Ball-by-ball IPL dataset provided through the Applied Decision-Making with Technology mentorship programme led by Rahul Chaubey, performance analyst based in England.
